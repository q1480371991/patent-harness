# 全局最小撰写清单（试验版）

> 本文档是「撰写时必守」的最小清单，用于试验：只读本清单 + 权要清单，能否写出基本合规的稿子。
>
> 本清单只含**撰写时边写边守的生成约束**（防止写歪的）；审查阶段会由脚本 + auditor 读全量 `global.md` 定向扫，不属于本清单。
>
> 权威出处：`references/rules/global.md`（G1-G7 全量规则）。本清单是其「撰写必守」子集，不新增规则；遇歧义以全量文件为准。

---

## 第一部分：动笔前（深读交底书）

1. 本案要解决的核心技术问题，锁定一个工业可行的。
2. 主流程：输入对象 → 处理步骤 → 输出结果 → 技术效果，能复述完整链条。
3. 每个关键数据、模型、参数、阈值、设备、模块的来源和用途。
4. 交底书批注 `> 💡 [批注 ...]` 圈定的创新点——按批注圈定展开，不自行另判；批注未圈定的按支撑环节处理，不擅自升格。
5. 交底书带算法名 ≠ 自动等于创造性：权要点名「××模型/××网络」的步骤才算创造性，才保留复杂模型；权要未点名的按功能性动作概括，不得把交底书算法原样堆进说明书。
6. 以下情况不得直接起稿，先回问用户：找不到核心技术问题 / 权1主流程无法从交底书支撑 / 关键特征来源不明 / 数据只出现无用途 / 批注与正文冲突 / 无法判断保护主题。

## 第二部分：撰写必守（生成约束）

### A. 链条闭合（G3-1 核心）

7. **每个新特征首次出现必须写清来源**——由哪个已有对象经计算/映射/提取/筛选/融合/训练/求解得到，不得让中间特征（矩阵、阈值、模型、点云等）突然出现。
8. **每个中间结果必须被后续步骤使用**——无后续用途的数据要删掉或改写为后续输入。
9. **跨数据形态转换必须写出转换链**——图像/矩阵/点云/坐标/控制信号属于不同层级，不得用前一层级的处理动作直接得到后一层级结果；必须「输入 → 中间处理 → 转换/求解 → 输出」。
10. **循环/迭代/替换类步骤不得写虚**——必须写明：①循环体（重执行哪一步）②每轮输入（以何对象替换/更新何对象）③终止判据（直到满足何条件）。禁止「迭代更新」「循环直至完毕」空动作收口。
11. **正向动作—输出闭合**——写「做什么」而非「不做什么」；否定表述仅两种合法形态（作触发条件「当未检出xx时，执行yy」须给出实际动作；作范围限定「不含xx的剩余数据」须有正向母集）。「不新增…，而是…」式否定前导一律删，直写正向动作。
12. **单分支判断用「当〔条件〕时，〔动作〕」，不带「则」**；双分支才用成对句式（当判定满足…则…；当判定不满足…则…）。判断句必须补出判断对象：把哪个对象判成什么（写「确定对应区域为微弱特征区域」，不写「确定微弱特征区域」）。

### B. 术语与措辞（G4/G5 核心）

13. **「预设」后不加「的」**——写「预设xx阈值」「预设xx模型」，不写「预设的xx」。
14. **「所述」只对跨句回指的方法链数据对象用**——首次引入不加、第二次及之后加；物理设备与采集硬件（无人机、传感器、相机等）一律不加「所述」。
15. **删不承载技术含义的虚字**——「大于或者等于」→「大于等于」、删「，并」。
16. **权要内删时间/程度类修饰限定词**（萌芽期/轻微等），留给说明书与背景技术。
17. **不为只被用一次、不被从权解释的中间量命名**——三跳改一跳（「对区域特征值集合归一化后加权求和，得到特征融合值」→「获取区域特征值并进行加权融合，得到特征融合值」）。
18. **禁用措辞自查**：`直接/即时/然后/可以/首先/其次/能够/例如/只有/一定/采用xxx工具/采用xxx模块` 不出现；不用「其/此/该」指代不明代词；不用「以」连接后续操作步骤。
19. **说明书禁权要体例措辞**——说明书正文不得出现「权利要求」「其特征在于」「不在权利要求中…」式取舍元叙述（说明书是复述权要内容，不是引用权要）。
20. **不写 AI 元叙述/自辩话术**——「本实施例为何这样写/为何不写某内容」一律删；若它替代了应给的技术内容（示例值、展开），按 G6-1 补回真实内容。

### C. 公式与数值（G6-1 核心）

21. **权要不写公式**——需计算写「根据 A 和 B 进行计算，得到 C」；公式放说明书。
22. **说明书公式写成 LaTeX 源码、独立成段、不带 `$` 定界**，段后紧跟参数解释段，不加编号。
23. **公式展开五项必填**——每个公式逐项给全：①每个符号 ②含义 ③单位（无量纲则注明）④取值范围 ⑤本实施例示例值。
24. **阈值/参数确定依据不能只写「预设/自适应设置/动态确定」**——说明书中必须写出对这些数据所做的具体动作（统计、换算、取分位值、求上界/下界、标定等），使可复现。
25. **说明书数量词禁用「若干个」「多个」**——必须写具体符号（如前 k 个）并给出示例取值与选取理由；量数词阿拉伯数字化（「三至五」→「3 至 5」）。

### D. 撰写流程（G7 核心）

26. **先 Markdown 后 DOCX**——权要一稿、全文一稿先用 Markdown 写，再写入 DOCX 模板。
27. **全文一稿按分块撰写法逐块写、逐块自检**——不一次性生成全文长文；逐块过对应阶段自检清单。

## 第三部分：写完自查

- [ ] 每个新特征都有来源？每个中间结果都被后续使用？
- [ ] 跨数据形态转换链完整（输入→中间处理→转换/求解→输出）？
- [ ] 循环/迭代步骤写清循环体、每轮输入、终止判据？
- [ ] 无「不执行/不生成/不参与…」式否定空动作收口？
- [ ] 判断句补出判断对象？单分支无「则」？
- [ ] 「预设」后无「的」？「所述」只对方法链数据对象跨句回用？
- [ ] 无虚字（大于或者等于、，并）？无时间/程度修饰词？
- [ ] 无禁用措辞（直接/可以/然后/例如等）？无「其/此/该」指代不明？
- [ ] 说明书正文无「权利要求/其特征在于」体例措辞？
- [ ] 无 AI 元叙述/自辩话术？
- [ ] 权要无公式；说明书公式五项必填齐全、参数解释段紧跟？
- [ ] 阈值/参数确定依据写明具体动作？数量词无「若干个/多个」？
