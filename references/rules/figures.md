# 附图规则

本文件用于全文稿阶段附图（图 1 = 方法主流程图，同时作为摘要附图）的**脚本自动生成**、DOCX 注入和附图返修任务。手画 Visio 指引与生图模型提示词规则已废止：附图不再手画、不再用生图模型出图。

## L9. 附图自动生成规则（唯一附图 = 图 1）

### L9-1 1级规则

- 附图集合 = **图 1 方法主流程图一张**（本所审核标准："一般画 1 个总的流程图即可"）。图 1 同时作为摘要附图；摘要附图的选择规则唯一出处是 `references/rules/full-draft.md` L5。
- 不要使用交底书中提供的图作为申请图（可能与已撰写内容不对应）；图 1 一律由脚本从**最新已审权要**重新生成：

  ```bash
  python3 scripts/render_patent_figure.py --claims-md <案件文件夹>/docs/权要稿.md \
      --output <案件文件夹>/docs/figures/figure-1.png
  ```

- 图 1 的内容由脚本从权要稿**构造保证**，禁止手工改图、改节点文字：节点数 = 权要 1 分号分句数；节点文字 = 权 1 对应分句逐字（去句末标点）；编号 S11..S1N 以水平引出线标注在矩形右侧外部，不写在矩形内；纵向单线单向箭头。发现节点表达不顺时，回头修权要/说明书后**重新生成**，不单独改图。
- 输出仅 **PNG**（300 DPI、黑白、宋体；任务宗旨 = 能成功插入 Word）。版式常量（框宽 520px、每行 26 字、框间距 50px、边距 30px）已经用户审核确认，未经用户明确要求不得调整。
- 注入交付 DOCX 用注入脚本（在 docx skill 的 unpack 目录上运行，之后照常 pack）：

  ```bash
  python3 scripts/insert_figures_docx.py <unpack目录> --png <案件文件夹>/docs/figures/figure-1.png
  ```

  自动完成：分节 2（摘要附图）居中嵌入图 1（默认宽 16.0cm）；分节 5（说明书附图）嵌入图 1 并确保其后有"图1"图题段（默认宽 12.3cm）；media/relationship/Content-Type 注册；两处已有图片时为**替换语义**（权要变更后重新生成、重新注入即完成附图更新）。分节 5 的其他既有附图不触碰。
- 无方法独立权要的案件：渲染脚本会因提取不到方法分句而报错停；此时按 `full-draft.md` L5 由用户自备代表主要保护主题的附图 PNG，仍用 insert_figures_docx.py 注入。
- 审核人明确要求额外附图（子流程图、系统结构图等）时：由用户自备图片文件，AI 不代画、不写生图提示词；附图说明（L7）随实际附图集合同步更新。
- 附图不得发明权要/说明书里没有的内容（脚本从权要构造，天然满足；用户自备图由用户负责）。

### L9-2 2级规则

- 子流程图默认不画（本所标准），仅在审核人点名要求时由用户自备。
- 图 1 节点编号 S11..S1N 与具体实施方式主步骤编号一致（L8-0 同构，脚本按分句序自动编号）。
- 权要 1 在任何轮次被改动后，figure-1.png 必须重新生成并重新注入，禁止沿用旧图。

### L9-3 遗留 OLE 附图的返修边界

- 旧案附图若为 Visio OLE 嵌入对象（`<w:object>`/`OLEObject`），老板批注要求"修改附图""调整文本框宽度一致"等图内排版修改时，AI 不在 DOCX XML 层处理——文本框宽度、连线、排版写在被嵌入的 `.vsd*` 内部，改 `<v:shape>` 容器尺寸无法触达图内文本框。**How to apply:** 用本 skill 重新生成图 1 PNG 后整图替换（insert_figures_docx.py 对既有 drawing 为替换语义；OLE `<w:object>` 场景脚本不识别，列为"待用户确认整图替换"并由 AI 以最小侵入方式将 object 段落替换为 drawing 段落后再注入）；其余文本批注照常注入留痕。
- 脚本生成的 PNG 附图收到批注时的返修路径 = 改权要（走权要联动流程）→ 重新生成 → 重新注入，不做图内微调。

### L9-4 自检清单

- figure-1.png 是否由**最新已审权要稿**生成（权要在本轮被改动过则必须重新生成）。
- 渲染脚本是否零 ERROR 退出（节点数 = 权 1 分句数、节点文字逐字一致由脚本构造保证，无需人工比对）。
- 注入脚本是否输出分节 2 与分节 5 两条 OK 行；分节 5 是否含"图1"图题。
- 附图说明（L7）是否与实际附图集合一致（默认仅"图1为……流程示意图"一条）。
