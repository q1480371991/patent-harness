# scoring 摘录 — impl-auditor 专用

> 本文件是 `scoring.md` 的静态摘录（按路摘录的实体化文件），仅供主 agent 以**路径**传给 `impl-auditor`。**修改 `scoring.md` 评分项或前置纪律时，必须同步更新本文件**。计分方法与多路合并口径不在本摘录内——那是主 agent 的职责。

## 评分前置纪律（防 AI 自评虚高）

必须先逐条列出"规则编号 → PASS/FAIL → 证据（原文片段或位置）"，分数由证据汇总得出，不得跳过证据直接给分。无证据的 PASS 一律视为未检查。
