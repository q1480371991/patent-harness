# scoring 摘录 — claims-auditor 专用

> 本文件是 `scoring.md` 的静态摘录（按路摘录的实体化文件），仅供主 agent 以**路径**传给 `claims-auditor`。**修改 `scoring.md` 评分项或前置纪律时，必须同步更新本文件**（同步责任在改 `scoring.md` 的人）。计分方法与多路合并口径不在本摘录内——那是主 agent 的职责。

## 评分前置纪律（防 AI 自评虚高）

必须先逐条列出"规则编号 → PASS/FAIL → 证据（原文片段或位置）"，分数由证据汇总得出，不得跳过证据直接给分。无证据的 PASS 一律视为未检查。

## 本路 1 级硬规则（零容忍，任一 FAIL → 整体不通过）

- L1-1 全部：权要数量与结构、权 1 ≤400 字、权 1 解决技术问题、分号断行、一个句号、从权完整引用权 1 主步骤、从权依附选择与技术逻辑匹配、"所述"与"一种"用法、数据来源与用途、一条从权只解决一个问题、权要内无撞名（同名实体不指两义 = 完整性 FAIL）
- 断行/分号/从权粒度依附符合 `claims-format-standard.md`

## 本路 2 级质量规则（加权扣分，算百分比）

- L1-2 各条
- **从权依附关系两轨平权（见 `claims.md` L1-1）**：轨 A 逐句对应型（全拉平）与轨 B 分支＋局部链条型均为合格形态、无主次；多元化数值门槛（三项：直接依附权 1 ≤60%、连续链 ≤3、至少 1 条二级分支）**仅轨 B 适用**，任一不满足即扣分；轨 A 不适用该门槛、不判 FAIL。命中中间态（半拉平半分支、真实递进却硬拉平、多条从权抢同一分句）即扣分。
- **权要措辞紧凑七条（王工口径，X2607134）**：2 级质量项（见 `global.md` G4-1、`claims.md` L1-3）——“预设”后不加“的”、判断句“当…时”不带“则”且补出判断对象、删不承载技术含义的虚字、删时间/程度类修饰限定词、不为只被用一次且不被从权解释的中间量命名、“所述”只对需跨句回指的对象用、权 1 篇幅守恒
- **权重技术合理性四判（A18-A21，王工口径，X2607134）**：2 级质量项（见 `global.md` G3-1）——预处理不得把待识别目标当噪声删掉、聚类/合并/归并给全所有必要约束维度、置零/屏蔽/剔除不破坏下游运算上下文、区域整体异常用和值/均值类统计不用极值
- **L1-2 预设对象确定过程默认不占从权（W42）**：对以"预设的xx"引入的对象单列的从权，判定其确定方式本身是否构成保护点、删去后保护范围是否改变；二者皆否即建议改写该从权为其他实质技术内容（仍须满足权要总数=10，改写而非删条）。**边界**：本项判从权条目的占位价值；说明书同一判断链内预设对象数量的必要性归 impl-auditor（`full-draft.md` L8-2）

## 判定与报告要求

- 1 级：逐条 PASS/FAIL，FAIL 必须给【规则编号 + 原文位置 + 问题】。
- 2 级：逐条判定，不适用的条目注明理由（由主 agent 从分母剔除）。
- 报告结构按本路契约 Output Contract 执行；每个 PASS 必附原文引用片段。
